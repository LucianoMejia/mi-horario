Mi Horario

Arma tu horario ideal antes de matricularte: carga tus materias, compara secciones que se cruzan, personaliza los colores de cada clase y descarga tantas versiones como necesites.

Cómo usar Mi Horario

1. Agrega tus materias

Completa el nombre, grupo, día, hora de inicio y fin para cada clase. Puedes usar varias filas si una materia tiene más de una opción o si se reúne en distintos días.

2. Compara alternativas

Si una materia tiene varios grupos, agrégalos todos. El sistema buscará combinaciones sin cruces y te mostrará la mejor opción disponible.

3. Revisa y personaliza

Usa el selector de opciones para ver otras combinaciones, cambia colores y ajusta el rango de horas desde Personalizar.

4. Comparte o descarga

Usa “Compartir web” para invitar a otros a probar Mi Horario, usa “Compartir horario” para enviar tu combinación actual por enlace y descárgalo como imagen cuando estés satisfecho con la distribución.

Materias y secciones

Si un grupo se reúne varios días (ej. martes y jueves), agrega una fila por cada día con el mismo nombre de materia y de grupo. Si una materia tiene varios grupos posibles (ej. "Grupo 1" reunido martes y jueves, "Grupo 2" reunido martes y viernes), agrégalos todos con su propio número de grupo: el planificador armará automáticamente las combinaciones posibles entre todos los grupos de todas tus materias, sin cruces de horario. Usa el interruptor de la izquierda de cada fila para ocultar temporalmente una materia y ver cómo queda el horario sin ella, sin necesidad de borrarla.

Se actualiza automáticamente mientras editas tus materias.
